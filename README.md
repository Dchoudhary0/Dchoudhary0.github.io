## 🎀 How to get a live link (free, takes 2 minutes)

### Option 1: Netlify Drop (EASIEST — no account needed)
1. Go to **https://app.netlify.com/drop**
2. Drag the entire `portfolio/` folder onto the page
3. Get an instant live link like `https://random-name.netlify.app`
4. You can customize the URL in Netlify settings

### Option 2: GitHub Pages (free, permanent link)
1. Create a new GitHub repo named `dilpreet-choudhary-portfolio`
2. Upload all files in this folder
3. Go to **Settings → Pages → Deploy from branch → main**
4. Your link: `https://yourusername.github.io/dilpreet-choudhary-portfolio`

### Option 3: Vercel (free, fast)
1. Go to **https://vercel.com/new**
2. Import your GitHub repo or drag the folder
3. Click Deploy → instant live link
